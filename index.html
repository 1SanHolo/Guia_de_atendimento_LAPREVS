1. Qualidade de Segurado

4. Histórico Rural

5. Gastos Médicos Contínuos

Tem notas de remédios contínuos, fraldas ou alimentação especial não fornecidos pelo SUS?

Catálogo de Benefícios Previdenciários & Assistenciais

Previdenciário B31 / B91

Benefício por Incapacidade Temporária (Auxílio-Doença)

Incapacidade total e temporária para a atividade habitual. Carência de 12 contribuições mensais (dispensada em acidentes ou doenças do art. 151 da Lei 8.213/91).

Carência: 12 meses
Previdenciário B32

Benefício por Incapacidade Permanente (Invalidez)

Incapacidade total, definitiva e insuscetível de reabilitação profissional. Possibilidade de acréscimo de 25% para assistência permanente de terceiros.

Adicional: +25%
Assistencial B87 / B88

BPC / LOAS (Idoso 65+ e Pessoa com Deficiência)

Garantia de 1 salário mínimo sem exigência de contribuição ao INSS. Renda familiar per capita legal de até 1/4 SM ou até 1/2 SM flexibilizada na via judicial por gastos médicos.

Não exige carência
Previdenciário B80

Salário-Maternidade (Urbano e Segurada Especial)

Devido pelo parto, adoção ou aborto não criminoso. Segurada especial rural exige comprovação de 10 meses de atividade campesina anterior ao parto.

Prazo: 120 dias
Previdenciário B41

Aposentadoria Rural e Híbrida (Tema 1007/STJ)

Idade reduzida (60 anos homem / 55 mulher) em regime de economia familiar. A aposentadoria híbrida permite somar tempo rural remoto com tempo urbano.

Carência: 180 meses
Previdenciário B21

Pensão por Morte (Urbana e Rural)

Benefício pago aos dependentes do segurado falecido. Duração escalonada para cônjuges conforme idade do sobrevivente e tempo de união.

Não exige carência

function doGet() {
var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
var data = sheet.getDataRange().getValues();
var headers = data[0];
var rows = [];
for (var i = 1; i < data.length; i++) {
var obj = {};
for (var j = 0; j < headers.length; j++) {
obj[headers[j]] = data[i][j];
}
rows.push(obj);
}
return ContentService.createTextOutput(JSON.stringify(rows)).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
var p = JSON.parse(e.postData.contents);
if (sheet.getLastRow() === 0) {
sheet.appendRow(["id","data","nome","cpf","telefone","beneficio","status","atendente","obs"]);
}
sheet.appendRow([p.id, p.data, p.nome, p.cpf, p.telefone, p.beneficio, p.status, p.atendente, p.obs]);
return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON);
}
