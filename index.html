Roteiro de Entrevista Oral • O que perguntar na mesa

5 Perguntas Cruciais para o Acadêmico Novato Investigar:

Nunca finalize o atendimento sem ter a resposta clara dessas 5 questões:

1. "O senhor(a) trabalhou de carteira assinada ou pagou carnê nos últimos meses?"

Descobre se ele tem Qualidade de Segurado ou está no Período de Graça. Use o simulador da aba para calcular o prazo exato.

2. "Quantas pessoas moram na mesma casa e qual a renda de cada uma?"

Essencial para BPC/LOAS. Lembre-se: aposentadoria de valor mínimo ou BPC de idoso na casa NÃO conta na renda (Tema 1082/STJ).

3. "A doença/acidente aconteceu trabalhando na empresa ou foi no dia a dia?"

Define a Competência: se for acidente de trabalho (B91/B94 acidentário), a ação vai para a Justiça Estadual (TJMS). Se for doença comum, vai para o Juizado Federal (JEF).

4. "O senhor(a) já morou ou trabalhou na roça no passado?"

Abre a oportunidade de Aposentadoria Híbrida (Tema 1007/STJ) ou Aposentadoria Rural pura, salvando anos de carência que faltavam.

5. "O senhor tem gastos pesados com remédios, fraldas ou alimentação especial?"

Esses gastos fixos comprovados com receitas e notas fiscais podem ser abatidos da renda do CadÚnico para viabilizar a concessão judicial do BPC.

As 4 Etapas de Acolhimento do Protocolo LAPREVS

Compreenda a lógica processual desde a recepção até a petição inicial:

1

Teste do Interesse de Agir (Tema 350 / STF)

O assistido já formalizou o pedido perante o INSS? A via judicial pressupõe recusa administrativa comprovada.

Se NÃO deu entrada: Não ajuizar de imediato. Orientar a requerer pelo portal Meu INSS ou telefone 135. Gerar a guia de encaminhamento caso necessite de senha provisória.
Se SIM deu entrada: Exigir a Comunicação de Decisão com o motivo do indeferimento, ou certificar mora administrativa superior a 90 dias sem resposta.
2

Aferição Socioeconômica & CadÚnico

Verificação dos critérios de vulnerabilidade para benefícios assistenciais (BPC/LOAS) e pensões humanitárias.

  • • CadÚnico Atualizado: Exigência indispensável para BPC/LOAS e Pensão Especial de Feminicídio (revisão nos últimos 24 meses).
  • • Renda Per Capita: Somatório de rendas de todos os coabitantes sob o mesmo teto, abatendo despesas médicas continuadas não fornecidas pelo SUS.
  • • Exclusão Legal (Tema 1082/STJ): BPC ou aposentadoria de valor mínimo recebida por outro idoso da família não é computada na renda.
3

Coleta e Conferência Probatória

Inspeção dos documentos materiais indispensáveis conforme o tipo de benefício requerido.

Incapacidade: Laudos médicos detalhados com CID, CRM legível, data recente, exames complementares e histórico de afastamentos.
Rural / Segurado Especial: Autodeclaração rural, notas de produtor, contratos agrários e certidões civis com profissão de lavrador.
Tempo / Idade: Extrato CNIS completo, CTPS físicas anotadas e averbações de tempo militar ou especial (PPP).
4

Instrução e Encaminhamento

Finalização do atendimento e direcionamento correto conforme o conjunto documental.

Documentação Completa: Formalizar a abertura do PAJ, cadastrar a pretensão em face do INSS e encaminhar à fila de redação da petição inicial.
Documentação Pendente: Emitir a folha do Gerador de Encaminhamentos informando exatamente qual órgão procurar (CRAS, Posto de Saúde, Banco ou Agência do INSS).

Configuração da Planilha em Nuvem

Conecte os 3 computadores a uma única Planilha do Google

Cole aqui o link gerado na implantação do Apps Script na sua conta Google.

Como criar em 2 minutos no Google Drive:
  1. Abra o Google Sheets (Planilhas) e crie uma planilha chamada "Atendimentos LAPREVS".
  2. No menu superior, clique em Extensões > Apps Script.
  3. Apague tudo que estiver lá, cole o código fornecido abaixo e clique em Salvar (💾).
  4. Clique no botão azul Implantar > Nova implantação.
  5. Selecione o tipo App da Web, defina "Quem pode acessar" como "Qualquer pessoa" e clique em Implantar.
  6. Copie a URL do App da Web gerada e cole no campo acima nos 3 computadores.
Código para o Apps Script (Copie e Cole): 
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var rows = [];
  for (var i = 1; i < data.length; i++) {
    if (data[i][0]) {
      rows.push({
        id: data[i][0],
        data: data[i][1],
        nome: data[i][2],
        cpf: data[i][3],
        telefone: data[i][4],
        atendente: data[i][5],
        beneficio: data[i][6],
        status: data[i][7],
        obs: data[i][8]
      });
    }
  }
  return ContentService.createTextOutput(JSON.stringify(rows)).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["ID", "Data", "Nome", "CPF", "Telefone", "Atendente", "Benefício", "Status", "Observações"]);
  }
  var payload = JSON.parse(e.postData.contents);
  if (payload.action === "save") {
    var a = payload.data;
    sheet.appendRow([a.id, a.data, a.nome, a.cpf, a.telefone, a.atendente, a.beneficio, a.status, a.obs]);
  } else if (payload.action === "sync_all") {
    sheet.clear();
    sheet.appendRow(["ID", "Data", "Nome", "CPF", "Telefone", "Atendente", "Benefício", "Status", "Observações"]);
    payload.data.forEach(function(a) {
      sheet.appendRow([a.id, a.data, a.nome, a.cpf, a.telefone, a.atendente, a.beneficio, a.status, a.obs]);
    });
  }
  return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON);
}
